# Agentic LLM for Business

An AI platform that brings agentic workflows and chain-of-thought reasoning to everyday business users—especially those working in Excel- and PowerPoint–style environments.

**Core Workflow:** Plan → Revise → Build

## Implementation Plan

The structured implementation plan lives in [`implementation-plan/`](./implementation-plan/README.md). It contains:

- **Preconditions** — Global and per-workstream prerequisites
- **Work streams** — Data connectivity, knowledge base, agent core, table interface, query execution, slide generation, database, go-to-market
- **Actions** — Concrete tasks for each deliverable
- **Checks and guardrails** — Validation criteria and safety limits

See the [plan README](./implementation-plan/README.md) for the full directory structure and dependency graph.
