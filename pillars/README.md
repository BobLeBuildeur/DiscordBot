# Pillars

**Pillars** are core concepts that must be observed to ensure success. They describe the uncompromising truths we follow—any decision needs to be aligned with them.

## Structure

Each pillar is a markdown file. The **filename** is the pillar name (e.g. `user-first.md`, `security-by-default.md`).

### Required

Every pillar file must contain a **single paragraph** stating the uncompromising truth. This is the non-negotiable principle.

### Optional

The paragraph may be followed by:

- **Do's and Don'ts** — Guidelines for applying the pillar
- **Policies** — Rules or standards derived from the pillar
- **Examples** — Concrete illustrations of alignment or violation

## Principles

- **Keep pillars short and concise**
- One pillar = one truth
- When in doubt, the paragraph is the source of truth; the rest supports it

## Adding a Pillar

1. Create a new `.md` file in this directory
2. Name the file after the pillar (kebab-case recommended)
3. Write the uncompromising truth in one paragraph
4. Add do's/don'ts, policies, or examples as needed
