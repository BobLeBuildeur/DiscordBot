# Small Steps Toward User Value

All work must contribute to the final goal through small, focused changes that move the product forward in a way an end user can interact with. Prefer agile, incremental progress over large, costly moves that delay usable outcomes.

## What it means

- Keep plans and changes small and focused on the objective.
- Make progress in ways that produce something an end user can interact with.
- Prefer incremental delivery over large batches of work.

## Rule of thumb

If a change does not create clear progress toward user-visible value, make it smaller or defer it.
